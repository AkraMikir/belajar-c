## 📝 Rincian Tugas

### 1. Tugas 1 (`tugas1.c`)
- **Tugas 1 (Dasar):** Biodata Diri (Nama, Asal Kota, Hobi).
- **Tugas 2 (Menengah):** Pola Segitiga Bintang bertingkat 5.
- **Tugas 3 (Tantangan):** Cetak Struk Belanja rapi menggunakan format tabulasi `\t` dan kalkulasi total belanja.

**Kompilasi & Jalankan:**
```bash
gcc tugas1.c -o tugas1.exe
.\tugas1.exe
```

---

### 2. Tugas 2 (`tugas2.c`)
- **Tugas 1 (Dasar):** Konversi Suhu (Celsius ke Fahrenheit dan Kelvin) dengan tipe data `double`.
- **Tugas 2 (Menengah):** Pengecekan ukuran memori tipe data (`char`, `short`, `int`, `long`, `float`, `double`) menggunakan `sizeof()`.
- **Tugas 3 (Tantangan):** Eksperimen Jebakan Integer Division (`5 / 2 = 2`) dan perbaikannya menggunakan Type Casting `(double)5 / 2 = 2.50` lengkap dengan penjelasan teoritisnya.

**Kompilasi & Jalankan:**
```bash
gcc tugas2.c -o tugas2.exe
.\tugas2.exe
```
